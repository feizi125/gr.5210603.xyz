# 澜联 LANLINK · 个人联系方式展示站

纯静态网站，可直接部署到 GitHub Pages。展示头像、姓名、职位、个性标签、联系方式列表与二维码，支持管理员登录后在线编辑资料、上传头像与二维码图片。

## 文件结构

```
lanlink-澜联/
├── index.html          页面结构
├── style.css           样式（液态玻璃名片风）
├── app.js              逻辑（展示 / 登录 / 编辑 / 二维码）
├── lib/qrcode.min.js   本地二维码生成库（qrcode-generator）
└── README.md           本说明
```

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（例如 `lanlink`）。
2. 把本目录全部文件上传到仓库（网页端 Add file → Upload files 即可）。
3. 仓库 Settings → Pages → Branch 选择 `main`，目录选 `/ (root)`，保存。
4. 稍等 1-2 分钟，访问 `https://你的用户名.github.io/lanlink/` 即可。

## 使用方法

1. 打开网站，点击右上角齿轮图标。
2. 输入管理密码（默认 `admin888`，在 `app.js` 顶部 `ADMIN_PASS` 处修改后重新上传）。
3. 在编辑抽屉中：
   - 上传头像；
   - 修改姓名 / 职位 / 公司 / 个性标签；
   - 增删联系方式条目（电话、邮箱、微信、QQ、网址、GitHub、地址、其他）；
   - 为任意条目上传二维码图片（如微信二维码截图）；无图片时访问者看到的是自动生成的二维码；
   - 可将条目设为「隐藏」。
4. 点击「保存并发布」→ 立即在本机生效（保存在浏览器 localStorage）。

## 让修改对所有访问者生效

GitHub Pages 是静态托管，无服务器存储。要让你的资料对所有人可见：

1. 登录编辑并保存后，点击「导出 data.json」；
2. 把下载的 `data.json` 上传到仓库根目录（替换旧文件）；
3. 访问者打开网站时会自动读取 `data.json` 显示你的资料。

> 他人设备上的 localStorage 不会影响 `data.json` 的读取；你自己想看「线上版本」时，可清除该站点 localStorage 或使用无痕窗口。

## 说明

- 二维码全部由本地 `lib/qrcode.min.js` 生成，无外部请求；
- 「保存联系人」按钮下载标准 vCard（.vcf），手机可直接导入通讯录；
- 管理密码为前端校验，仅用于防止误改，不构成真实安全防护，请勿存放敏感信息。
